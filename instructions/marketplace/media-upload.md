# Загрузка иконки и скриншотов в кабинет вендора

## Коротко

Картинки в настоящем качестве загружай сразу через сайт кабинета. MCP b24 для этого не подходит. Через MCP заполняй тексты, ставь иконку и скриншоты по порядку, гоняй проверки.

## Что не работает

`apps_upload_media` принимает файл только как base64-текст внутри вызова. Модель набирает этот текст сама, загрузки из файла или по ссылке у инструмента нет.

- Проходит только совсем маленький файл: JPEG 256×256 на ~6 КБ.
- Иконка на 24 КБ уже сломалась: `MEDIA_TYPE_UNSUPPORTED`.
- Кадры по 46–75 КБ, даже ужатые до 1422×800: часть получила `VALIDATION` на `contentBase64`, один принят обрезанным (15 КБ из 46). Это хуже явной ошибки.
- Скачать загруженный файл и сверить его из облачной сессии нельзя: сеть закрывает util.1c-bitrix.ru.
- Значит, не трать время ни на base64 вручную, ни на десяток агентов.

## Что сработало (2026-11-25, «Звонок вовремя»)

1. Антон входит в кабинет vendors.bitrix24.ru во встроенном браузере Claude на Mac. Пароль вводит только он.
2. Сессия на Mac на пару минут выкладывает PNG во временную папку на 1daa.ru и передаёт их странице кабинета.
3. Страница сама грузит файлы обычной формой «Добавить скриншоты», без пережатия.
4. Временная папка на сервере сразу удаляется.
5. Через MCP (`apps_get`, `apps_precheck`) проверяем, что иконка и все кадры на месте и стоят по порядку.

Запасные пути:

- Claude in Chrome в Chrome Антона, если он там уже вошёл в кабинет. Нужно его «да».
- Скрипт на Mac, который читает файл и сам вызывает MCP b24 с токеном Антона. Нужно его «да», токен не попадает в чат и git.
- Антон перетаскивает файлы сам: «Описание» → ru → «Скриншоты».

## Ограничения кабинета

- Иконка: PNG или JPEG, квадрат, не меньше 256 px, не больше 1 МБ. Готовим 650×650.
- Скриншоты:
  - PNG или JPEG, не больше 4 МБ каждый;
  - меньшая сторона не меньше 800 px, размер не больше 1920×1080;
  - от 1 до 50 штук.
  - Готовим 10 кадров 1920×1080; первый станет обложкой.
- После загрузки картинок: `apps_precheck`, затем один запуск ИИ-проверки. Отправка на модерацию — только после «да» Антона.
